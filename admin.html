Entrar al editor

Para guardar cambios, este dispositivo necesita tu clave de GitHub. Se pide una sola vez y queda guardada solo aquí.

¿Cómo consigo la clave?
  1. Abre este enlace de GitHub (inicia sesión si te lo pide).
  2. En Expiration elige No expiration.
  3. Deja marcada la casilla public_repo y baja hasta el botón verde Generate token.
  4. Copia la clave que aparece (empieza con ghp_) y pégala arriba.

No compartas esta clave con nadie: con ella se puede modificar la carta.
